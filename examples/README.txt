RESIDUAL FICTIONAL EXAMPLES AND REGRESSION FIXTURES

All bundled records are invented for demonstration and tests. They are not survey microdata, personal records, or completed research results.

import/schools.csv and schools.xlsx: 24 fictional schools; tests of CSV/Excel import.
import/budget.html: 12 fictional institutions; tests of HTML tables and decimal formats.
demo/d006.csv and d008.csv: 160 fictional households and 560 fictional roster members; keys DEMO0001–DEMO0160. Tests include deliberate contradictions and unusual values.
planner_sample.csv, planner_cases.json, research_questions.json: authored model-regression fixtures, not independent accuracy benchmarks. Evaluation scripts write new output under private_outputs/.

Examples load only when explicitly selected. Change a value in a copy and import it to verify that the calculation uses the new input.
