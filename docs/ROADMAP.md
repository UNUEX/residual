# Roadmap

This is a direction for future work, not a list of available features or release dates.

## First priorities

- English interface localization with coverage for messages, reports and input-validation errors.
- Feedback on the complete import, schema review, plan approval and reproduction workflow.
- More import regression cases for spreadsheet structures, using invented examples.
- Accessible keyboard navigation and clearer error recovery.
- Easier installation without changing the local storage and model boundaries.

## Possible later work

- Additional bounded operations, including explicitly reviewed filters.
- More model compatibility checks with reproducible evaluation methods.
- A general-table MCP interface with explicit permissions and a clear data-sharing contract.

Each new operation needs an input contract, plan validation, deterministic calculation and reproduction support. Larger ideas should first demonstrate a useful, testable workflow.
