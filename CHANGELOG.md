# Changelog

## 0.5.0

- English is the default interface language; Kazakh, Korean and Simplified Chinese can be selected without clearing the current question or import configuration.
- Localized import validation, planning feedback, calculation explanations, model settings and report headings.
- Added operation guards for the supported languages, including year checks and column matching in Chinese.
- English sample spreadsheets and updated application screenshot.
- Regression checks for catalogue completeness, request isolation, unchanged user data and identical numeric results across languages.

## 0.4.0

Initial public release: local table import, schema review, bounded model plans, approved Python calculations, report exports and standalone reproduction.
